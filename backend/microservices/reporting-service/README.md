# Reporting Service

This is a Spring Boot microservice that provides the competitive programming reporting and analytics functionality in
the problem tracker application.

## Tech Stack

- Java Version 21
- Spring Boot
- Spring Data JPA (Hibernate)
- Spring Security
- Spring Cloud Config Client
- Spring Cloud Netflix Eureka Client
- Spring Boot Actuator
- Oracle DB
- Docker
- GitHub
- Git
- JWT Authentication
- Gradle

### Development-Related

- Spring Boot DevTools
- Spring Boot Configuration Processor

### Testing

- JUnit 5 [Planned]
- Mockito [Planned]

## Current Features

- JWT Authentication

## Potential Features

- View stats for a user on a problem
- View stats for a user on all problems
- View user activity reports (daily, weekly, monthly, yearly)
