# Authentication Service

This is a Spring Boot microservice that provides the competitive programming authentication functionality in the
problem tracker application.

## Tech Stack

- Java Version 21
- Spring Boot
- Spring Data JPA (Hibernate)
- Spring Security
- Spring Cloud Config Client
- Spring Cloud Netflix Eureka Client
- Hibernate Validator
- Spring Boot Actuator
- Oracle DB
- Docker
- GitHub
- Git
- JWT Authentication
- Gradle

### Development-Related

- Spring Boot DevTools
- Spring Boot Configuration Processor
- OpenAPI/Swagger API Documentation (via Javadoc)

### Testing

- JUnit 5
- Mockito [Planned]
- REST Assured
- H2 Database

## Current Features

- Authenticate a user with an email address and password
- Issue a JWT token
